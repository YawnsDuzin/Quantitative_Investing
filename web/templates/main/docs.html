시작하기

1. 회원가입

먼저 계정을 생성하세요. 이메일과 비밀번호로 간단하게 가입할 수 있습니다.

2. 데이터 수집

투자할 시장의 주식 데이터를 수집합니다. 메뉴에서 데이터 > 수집을 선택하세요.

3. 전략 선택

기본 제공되는 전략 중 하나를 선택하거나 커스텀 전략을 생성할 수 있습니다.

4. 백테스트 실행

선택한 전략의 과거 성과를 확인합니다.

전략

모멘텀 전략

과거 12개월 수익률이 높은 종목에 투자하는 전략입니다. 상승 추세가 지속된다는 가정 하에 운영됩니다.

모멘텀 = (현재가 - 12개월전 가격) / 12개월전 가격

가치 전략

PBR, PER이 낮은 저평가 종목에 투자합니다.

가치 점수 = 1/PBR + 1/PER (정규화)

퀄리티 전략

ROE가 높고 부채비율이 낮은 우량 기업에 투자합니다.

멀티팩터 전략

여러 팩터를 가중 평균하여 종합 점수를 산출합니다.

종합점수 = 0.4×모멘텀 + 0.3×가치 + 0.2×퀄리티 + 0.1×사이즈

백테스팅

백테스트 설정

  • 기간: 시작일과 종료일 설정
  • 초기 자본: 시뮬레이션 시작 금액
  • 수수료: 거래당 수수료율 (기본 0.15%)
  • 슬리피지: 체결 가격 오차 (기본 0.1%)
  • 리밸런싱: 매일/매주/매월/분기별

성과 지표

총 수익률전체 기간 수익률
연평균 수익률 (CAGR)연간 복리 수익률
샤프 비율위험 대비 수익률
최대 낙폭 (MDD)고점 대비 최대 하락폭
승률수익 거래일 비율

데이터 관리

지원 시장

  • 한국: KOSPI, KOSDAQ
  • 미국: NYSE, NASDAQ

데이터 종류

  • 가격 데이터: 시가, 고가, 저가, 종가, 거래량
  • 재무 데이터: PER, PBR, ROE, 부채비율, 시가총액

포트폴리오

포트폴리오 최적화

평균-분산 최적화를 통해 최적의 자산 배분을 찾을 수 있습니다.

  • 샤프 비율 최대화: 위험 대비 수익 극대화
  • 최소 변동성: 리스크 최소화
  • 동일 비중: 균등 배분

API

시스템은 RESTful API를 제공합니다.

GET /api/dashboard/stats - 대시보드 통계
GET /api/stock-search?q=삼성 - 종목 검색
POST /api/portfolio-optimizer - 포트폴리오 최적화
GET /api/indicators/{symbol} - 기술적 지표
